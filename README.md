A program that writes one horror story of exactly two sentences to `/output/entry.txt`: "The mirror in the hallway finally stopped showing me a second late. Now it shows me a second early, and it keeps smiling first." (127 characters, inside the 400-character cap.) The first sentence is a small relief — the lagging mirror is fixed — and the second turns it: the mirror now anticipates, and it smiles before I do. The horror stays implied, never explained.

## Run it

```sh
python3 main.py
```
